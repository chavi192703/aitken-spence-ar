# Aitken Spence Annual Report 2025/26 microsite

An interactive, single-page microsite built from the Aitken Spence PLC Integrated Annual Report 2025/26.

- `index.html` – page markup
- `site.css` – styles and animations
- `app.js` – charts, Aria the mascot and chat guide, report builder and summary PDF
- `assets/` – mascot layers, logos
- `vendor/` – Chart.js 4.4.1 and jsPDF 2.5.1, copied from npm (`npm install && npm run vendor` refreshes them)

It is a static site with no build step. Deploy the repository root as-is.
